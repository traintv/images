# Приложение для обрезки фотографий

## Обзор

Это простое веб-приложение, которое позволяет пользователям загружать изображения, обрезать их и скачивать обрезанную версию. Приложение построено с использованием HTML, CSS, JavaScript и библиотеки `Cropper.js` для функциональности обрезки.

## Структура проекта

```
.
│   .gitignore
│   cropped-image.png
│   package-lock.json
│   package.json
│   
├───.parcel-cache
│       771a09cabdd0e280-AssetGraph-0
│       7f973df67467291d-AssetGraph-0
│       b42dcb70dd9637c0-BundleGraph-0
│       data.mdb
│       lock.mdb
│       requestGraph-39676f90f93af3b1-0
│       requestGraph-nodes-0-39676f90f93af3b1-0
│       snapshot-39676f90f93af3b1.txt
│       
└───src
        index.html
        main.js
        style.css
```

- **`.gitignore`**: Файлы и папки, которые не должны быть отслеживаемы Git.
- **`cropped-image.png`**: Пример обрезанного изображения (может быть удален).
- **`package-lock.json`**: Автоматически генерируемый файл, который фиксирует точные версии зависимостей.
- **`package.json`**: Файл конфигурации проекта, содержащий зависимости и скрипты.
- **`.parcel-cache`**: Кэш Parcel, используемый для ускорения сборки.
- **`src/`**: Папка с исходным кодом приложения.
  - **`index.html`**: Основной HTML-файл.
  - **`main.js`**: Основной JavaScript-файл, содержащий логику приложения.
  - **`style.css`**: Файл стилей для оформления приложения.

## Установка и запуск

1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/yourusername/cropping-app.git
   cd cropping-app
   ```

2. **Установка зависимостей:**
   ```bash
   npm install
   ```

3. **Запуск приложения:**
   ```bash
   npm start
   ```

4. Откройте браузер и перейдите по адресу `http://localhost:1234`, чтобы увидеть приложение в действии.

## Функциональность

- **Загрузка изображения**: Нажмите кнопку "Upload image", чтобы выбрать изображение для обрезки.
- **Обрезка изображения**: После загрузки изображения используйте инструмент обрезки, чтобы выбрать область, которую хотите сохранить.
- **Скачивание обрезанного изображения**: Нажмите кнопку "Download new image", чтобы скачать обрезанную версию изображения.

## Зависимости

- **Cropper.js**: Библиотека для обрезки изображений.
- **Parcel**: Инструмент сборки для веб-приложений.
